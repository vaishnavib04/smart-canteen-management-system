# Smart Canteen Pre-Order and Inventory Management System

A DBMS Level 3 project for managing canteen food orders, inventory, and pickup slots.

## Technology Stack

- Frontend: Next.js
- Backend/API: Next.js Route Handlers
- SQL Database: MySQL
- NoSQL Database: MongoDB
- Version Control: Git and GitHub

## Project Status

Stage 3 development is in progress.

## Planned Features

- Student ordering and order history
- Food category and menu management
- Inventory tracking and low-stock alerts
- Role-based access for students, staff, and administrators
- SQL transactions and advanced database features
- MongoDB activity and order-event logging
